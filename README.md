# ☕ cafe-landing

가상의 카페 "모닝빈"을 소개하는 간단한 정적 랜딩 페이지 예제입니다. AI 에이전트 수업 실습용으로 만들었습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 구조 (메뉴 바, 히어로, 대표 메뉴, 소개, 오시는 길, 푸터) |
| `style.css` | 디자인 스타일 (커피색 톤, 모바일 반응형) |

## 실행 방법

별도 설치 없이 `index.html` 파일을 브라우저에서 열면 됩니다.

## 참고

- 카페 이름, 메뉴, 가격, 주소, 전화번호는 모두 예시 데이터입니다. 실제 내용으로 바꿔서 사용하세요.
